# OSBP Procedures Manual (digital prototype)

Concept prototype of the EAC One-Stop Border Posts Procedures Manual as a searchable, offline-capable web app. Static site served by GitHub Pages; no build step.

Content: EAC One-Stop Border Posts Procedures Manual, 2nd edition (September 2023), © 2024 East African Community, used as sample content for a proposal demo. Not an official EAC or IOM product.

To update the offline cache after changing content, bump `VERSION` in `sw.js`.
